# MLR Project (Synthetic Cars Dataset)

This folder contains:
- `data/cars_synthetic.csv` — a synthetic dataset for multiple linear regression (mpg prediction).
- `MLR_end_to_end.ipynb` — a complete notebook with EDA, preprocessing (ColumnTransformer), model training, evaluation, VIF, and a 3D regression plane example.
- `requirements.txt` — libraries commonly used to run the notebook.

## Quick Start
1. Open the notebook `MLR_end_to_end.ipynb` in Jupyter / VS Code.
2. Run all cells. The dataset path is already set to `data/cars_synthetic.csv`.
